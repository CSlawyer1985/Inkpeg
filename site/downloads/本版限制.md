# 2.0.0 预览版限制

更新：2026-10-12，build 5，最低 macOS 14.0。本轮候选版与旧 0.1.0 内部包分开标识，不能作为正式安全发行。

| 范围 | 当前状态 |
| --- | --- |
| 材料、记事、恢复与清理 | 已实现；原件不改，草稿与恢复记录受保护。完整本轮自动回归数量、命令和结果见随网站分发的 `verification.json` 及仓库 VERIFICATION.md。 |
| 微信／Codex 输入框拖入 | 提供纯文字、PNG／TIFF、可读取导出副本和 Finder promise；实际外部应用接收仍为 NOT VERIFIED。可用“复制 → 目标应用 ⌘V”。网页演示不等于原生跨应用验收。 |
| 满绳与横向滚动 | 满绳保留全部卡片；触控板左右滚动、Shift＋滚轮、左右箭头浏览。滚动不写状态；旧版取下卡不会自动重挂。物理触控板和真实跨窗口空白穿透仍待验收。 |
| 最近取下 | 可主动重新挂回，保留材料与版本；完整事项、历史管理、固定操作和双栏对照尚未实现。既有固定状态受清理保护。 |
| 一键隐私 | 持久隐私状态、窗口遮盖和异步回调保护已接通并有框架测试；真实桌面第一帧、VoiceOver 与屏幕合成效果未完成实机验收。 |
| 系统与架构 | 候选包检查实际 arm64＋x86_64 slice 与最低系统，不把交叉编译当作 Intel／macOS 14 实机通过。当前宿主 Apple Silicon／macOS 26.6.2；多屏、全屏、睡眠、重启和完整中文输入法未完成实体矩阵。 |
| 平台降级 | 私有 Spaces 能力未知时，自动显露保守关闭；手动菜单、快捷键与可访问入口保留。实机能力只读探针不等于真实全屏操作验收。 |
| 签名、公证与安装 | 无 Developer ID 签名／Apple 公证。安装助手仅在用户明确运行后处理新安装文夹的隔离属性，不更改全局系统安全；linker ad-hoc 不是身份认证。DMG、隔离复制、资源执行与合成资料保护可自动核验；Finder 图标、应用切换器、首次完整启动、Gatekeeper 和真实升级交互为 NOT VERIFIED。 |
| 浏览器与手机 | Chromium 的真实渲染和触摸模拟有证据；Safari／Firefox、实体手机软键盘／缩放待验收。 |
| 网络与资料库 | 无业务联网功能，完整运行时网络观察未完成；资料库位置固定，无自动更新。 |
| 恢复与清理 | 清理移到系统废纸篓，不自动清空；未知／损坏恢复记录保守阻断。找回文件后可重新挂入，旧卡片元数据不会自动重建。 |
| 品牌 | 自有弯绳、暖纸、红夹图标，不使用上游图标或演示图作发行资产。实际 iconset、ICNS、plist 与包内资源分别核验。 |

历史设计、审计、计划及旧包数字只说明当时状态；本候选版以源码指纹、包 SHA 和本轮验证记录为准。当前包不是经 Apple 安全审查的发行版，SHA 只证明文件一致性。
