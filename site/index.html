首次安装，或从旧版升级。

  1. 先确认来源和系统要求。

    macOS 14 及以上。核对安装包与同版校验值，再开始首次安装。

  2. 打开 DMG，拖入“应用程序”。

    从“应用程序”启动。文夹在屏幕上方，鼠标靠近顶部或按 ⌃⌥T 展开。

  3. 这是预览包。

    尚无 Developer ID 签名和 Apple 公证。首次打开可能需要你核对来源后，在系统设置中确认。

Intel 架构已编译并随包提供，Intel 实机验收仍待完成。微信／Codex 的真实拖入接收、旧系统和多屏也待实测。阅读安装步骤与本版限制 →

再问几句。

这是文件管理器或永久收藏夹吗？

文夹主要放眼前正在使用的材料。完整事项、历史列表和双栏对照尚未实现。取下卡片会保留副本，清理前请逐项核对。

能拖到微信、Codex 等输入框吗？

当前提供纯文字、PNG／TIFF 和可读取文件副本，并保留 Finder 文件拖放。具体输入框的实际接收仍待验收；不接收时可用“复制 → 目标应用 ⌘V”。上面的桌面用于体验操作方式，不会调用你电脑里的应用。

为什么访问仓库需要权限？

Inkpeg 仓库目前是私有的，只有获授权的 GitHub 账号能访问。页面下载提供的是本次内部测试包，不需要通过 GitHub 下载。

支持哪些电脑和系统？

当前包包含 Apple Silicon（M 系列）与 Intel（x86_64），最低 macOS 14。编译支持不等于所有机器都已验收，尤其 Intel、较旧系统和首次安装还需要实际测试。
