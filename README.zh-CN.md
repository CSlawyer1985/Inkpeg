# Inkpeg · 文夹使用说明

当前为 0.1.0 内部测试版。安装与版本状态见 [README](README.md) 和 [安装教程](docs/inkpeg/INSTALL.md)；正式发布所需的剩余工作见 [已知限制](docs/inkpeg/KNOWN-ISSUES.md)。

## 先挂一份材料

将图片、文字片段或本地普通文件拖到屏幕上方绳子附近的高亮接收区。也可以复制内容后，右键小红段或打开回形针菜单，选择“粘贴挂入”；本地文件可用“挂入文件”。新工作区默认手动挂入，不会自动收集整个剪贴板。

接收的是独立副本，原件留在原处。PDF、视频等按普通文件托管，并不代表支持预览或理解所有格式。当前文字上限 1 MiB，图片 16 MiB／32M 像素，普通文件 64 MiB，每批最多 32 项／64 MiB；超限会拒绝并提示。

屏幕顶部绳子会随鼠标靠近而展开；`⌃⌥T` 显示或隐藏材料架。小红段位于绳子从左起约 61.8% 的位置：单击记事，右键打开操作菜单。设置可从这个菜单或回形针菜单进入。

## 查看、复制与拖出

- 普通材料单击复制；记事卡单击继续记事。
- 右键卡片可查看来源和详情、复制或打开副本、编辑／标注支持的副本、取下卡片。来源可补录，不会凭空生成原始出处。
- 拖到文件夹时提供导出副本；原件与托管材料不因拖出被移动。
- 微信和 Codex 输入框的直接拖入仍需完善。当前先在卡片菜单选择“复制”，再到目标输入框按 `⌘V`；图片和文件的最终接收方式取决于目标应用。

“取下”会从绳上隐藏卡片，副本继续保留。当前超出显示容量时会取下较早的未固定卡；还没有触控板横向滚动或完整历史列表。它们可能进入后续清理范围，清理前核对名称。

## 新建和继续记事

点击小红段打开记事窗口，支持键入和 `⌘V` 粘贴。无需另填标题，首行用作卡片标题。边写边保存草稿；注意窗口中的保存状态。

按 `⌘Return` 或“挂上去”后才成为绳上卡片。空白正文与尚在输入法候选组合中的文字不会挂入。普通 Return 换行。Esc、关闭或失焦会收起窗口并保留草稿；再次点小红段恢复未挂出的记事。已有记事卡继续编辑同一张。

保存失败时保留窗口内容并提示，等待重试成功后再退出。崩溃或强制退出不能保证最后一次尚在写入的输入已经落盘。

## 设置

“挂入”页可开关剪贴板自动接收，选择图片、文字、文件，以及是否接收启动时剪贴板已有内容。自行复制出去的内容和已经保存的重复内容不会再次建卡。快速连续复制可能落在轮询间隔内，不能保证接收每次变化。

截图目录监听单独配置：桌面仅接收有系统截图标记的新图片；指定的专用目录可接收其他截图软件新保存的图片。已有文件不会补挂。文夹不接管或修改系统截图保存设置。

“存储”页显示托管材料、导出副本和草稿／恢复记录的占用，提供“在 Finder 中显示”与“预览清理…”。底部链接为 [chenshi.ai](https://chenshi.ai)。本版资料库位置固定，尚不支持在设置中自定义。

## 清理副本

打开“设置 → 存储 → 预览清理…”，检查名称、项数与占用，确认后点击“移到废纸篓”。

默认包含已取下且未固定的托管材料，以及超过 24 小时的临时导出。原件、绳上、固定、待审资料及编辑／恢复草稿会保留。已打开但尚未改动的记事也保守保护，可能要发布或重启后才重新判断。预览之后材料发生变化时，旧确认会被拒绝，需要重新预览。

清理是移入系统废纸篓，应用不自动清空。真正释放磁盘空间需要你自行清空废纸篓；此后无法通过本应用恢复。文件可从废纸篓找回后重新挂入，旧卡片元数据不会自动重建。清理记录本身会保留，因此清理很小的文件后，总占用可能短暂增加。

## 资料库、备份与恢复

默认位置 `~/Library/Application Support/Inkpeg/`：

- `Materials/`：材料及版本；原件在导入前的位置保留。
- `Exports/`：复制文件、外部打开等生成的临时导出。
- `Drafts/`、`Transactions/`：草稿及编辑恢复记录。
- `CleanupRecords/`：清理前清单、状态和废纸篓结果。
- `state.json`、`state.previous.json`：当前和备用状态及设置。

完整备份前先正常退出应用，再复制整个 Inkpeg 资料库。不要单独删状态文件或只恢复部分目录。应用提示需要恢复时先处理恢复窗口；未知或损坏记录会阻止清理，避免误清未完成编辑。
