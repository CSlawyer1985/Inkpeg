# 文夹 Inkpeg 安装、升级与卸载

适用：0.1.0 内部测试版，Apple Silicon（M 系列），工程最低 macOS 14。当前包未经 Developer ID 签名和 Apple 公证；本机验收环境为 macOS 26.6.2，较旧系统及首次下载的新机尚待实测。

## 1. 核对安装包

你应收到同一版的 `.dmg`、`SHA256SUMS.txt` 和安装说明。确认来源是开发者给你的包，再开始安装。当前没有文夹正式在线下载地址。

想检查下载是否完整，可在“终端”运行 `shasum -a 256 `（末尾留空格），将 DMG 拖入终端后按回车，把结果与 `SHA256SUMS.txt` 中该 DMG 的校验值比较。文件名带日期和 arm64，版本之间不混用校验值。校验值只能核对文件一致性；如果文件与校验文件都来自不可信来源，不能据此确认安全。

## 2. 首次安装

1. 双击 `.dmg`，打开其中的“先读我-安装与使用.txt”。
2. 将 `Inkpeg.app` 拖到同一窗口的“应用程序”快捷方式。如果系统询问权限，按自己的安装意愿确认；没有管理员写入权限时，可复制到自己主目录的“应用程序”。
3. 拷贝完成后，在“应用程序”中打开 `Inkpeg.app`。请不要直接从 DMG 运行，也不要同时启动多个副本。
4. 用完安装窗口后弹出 DMG。文夹位于屏幕上方，默认不显示 Dock 图标；鼠标靠近菜单栏展开，`⌃⌥T` 显示或隐藏。

## 3. 未签名首次打开

如果提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”，在确认来源及校验值后：

1. 先尝试打开已复制到“应用程序”的 `Inkpeg.app`，关闭提醒。
2. 打开“系统设置 → 隐私与安全性”，向下找到此次被阻止的文夹／Inkpeg。
3. 点击“仍要打开”，再按系统提示确认“打开”；如需密码，由你自行输入。

这是为这一个应用建立例外，不需要关闭全局安全检查。步骤依据 [Apple：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)（2026-10-10 查阅）。具体按钮和提示可能随 macOS 版本变化。安装包不包含自动移除下载隔离标记或更改安全设置的脚本。

如果提示“已损坏”、检测到恶意软件，或者找不到“仍要打开”：先停止，核对校验值、重新取得同版包并记录提示；不要直接认定只是签名问题。设备由单位管理时，联系管理员。可以把系统版本、芯片类型及提示发给开发者，避免附上私密材料。

## 4. 第一份材料与设置

- 将图片、文字或普通文件拖到顶部绳子附近，或右键小红段选择“粘贴挂入”“挂入文件”。
- 小红段单击打开记事：`⌘V` 粘贴，`⌘Return` 挂上去，普通 Return 换行。请等保存状态确认后退出。
- 右键小红段或打开回形针菜单进入“设置”。新工作区默认手动挂入；自动剪贴板和截图目录接收按需开启。
- 微信／Codex 直接拖入兼容尚待完善，先使用“复制 → 输入框 ⌘V”。超出显示容量的旧卡会取下保留副本；横向滚动尚未实现。

## 5. 存储与清理

默认资料库在 `~/Library/Application Support/Inkpeg/`。访达按 `⇧⌘G`，输入该路径查看，或在“设置 → 存储”点击“在 Finder 中显示”。当前不能更换位置。

“预览清理…”列出已取下且未固定的资料及超过 24 小时的临时导出。确认后移入系统废纸篓，原件、绳上／固定／待审资料及编辑／恢复草稿保留。满绳自动取下的旧卡也可能在清单中，请逐项检查。

应用不自动清空废纸篓。真正释放空间需要你自行清空；清空后不能通过文夹恢复。清理前后的记录保留在资料库。回收文件可以从废纸篓找回，再重新挂入；旧卡片元数据不会自动恢复。

## 6. 升级与回退

1. 等待记事保存完成，处理未保存编辑和待恢复提示，再从回形针菜单选“退出”；窗口有焦点时也可用 `⌘Q`。
2. 退出后备份整个 `~/Library/Application Support/Inkpeg/` 文件夹，另存一份带日期的副本。不要只备份 `state.json`。
3. 在“应用程序”找到旧 `Inkpeg.app`。保留一份旧应用作回退，再把原位置的旧 app 移到废纸篓；不要动资料库。
4. 从新版 DMG 将 `Inkpeg.app` 拖入“应用程序”，再从这个位置启动。必要时按上一节对新版自行确认。
5. 检查既有卡片、草稿和接收设置是否保留。本版没有自动更新功能。

回退时先退出新版，再更换为保留的旧 app。旧版是否能读取后续新版本资料库，需看对应版本说明。若要恢复备份，先保护当前新增材料；原路径存在同名资料库时停止，不能直接覆盖合并。

## 7. 卸载

先正常退出，把“应用程序”中的 `Inkpeg.app` 移到废纸篓。只移除 app 会保留资料库，便于重新安装。

需要连资料一起移除时，先完整备份并确认不再需要，再将整个 `~/Library/Application Support/Inkpeg/` 移到废纸篓。导入前的原始文件不受影响。不要自动清空废纸篓，也不要在应用运行中操作资料库。

## 8. 常见问题

- **看不到绳子**：鼠标靠近屏幕顶部，试 `⌃⌥T`；避免同时运行旧试用版。无 Dock 图标是当前菜单栏应用的正常行为。
- **新版还是旧界面**：确认旧版已退出，从“应用程序”启动新包，而不是旧的开发试用路径；不要双开同一资料库。
- **没有清理内容**：当前仅清理已取下、未固定且不受草稿保护的副本和超过 24 小时的导出；近期或编辑中的资料保留。
- **暂时无法清理**：先处理待恢复内容。未知／损坏记录会保守停止，请保留原目录并向开发者反馈。
- **粘贴或拖入失败**：记事窗口支持纯文字 `⌘V`；微信／Codex 拖入仍待完善，先复制到剪贴板再由目标应用粘贴。
