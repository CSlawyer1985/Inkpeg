# 文夹 Inkpeg · 安装与升级

适用：2.0.0 公开预览版（build 3），macOS 14+，Apple Silicon＋Intel 通用包。

## 首次安装：三步

1. 在 [官网](https://inkpeg.chenshi.ai/#download) 下载并打开 DMG。
2. 双击安装包里的“安装文夹.command”。终端打开后按回车确认，等待“安装完成”；助手会复制应用、为这一份文夹准备首次打开并启动它。
3. 鼠标移到屏幕顶部，或按 Control＋Option＋T。拖入一份图片、文字或文件就能开始使用。

如果安装助手被 macOS 拦截：先尝试打开一次，再到“系统设置 → 隐私与安全性”点击“仍要打开”，然后重新运行助手。系统密码或确认由你自行完成。

安装助手优先使用可写的系统“应用程序”，否则使用你的个人“应用程序”目录。它先检查应用与随包校验文件，保留旧 App，不操作资料库、不关闭全局安全检查。当前没有 Developer ID 签名或 Apple 公证；助手不等于 Apple 的安全审核。

## 升级前

先等草稿保存完，处理编辑和恢复提示，从回形针菜单选择“退出”。退出后完整备份 `~/Library/Application Support/Inkpeg/`，不要只备份 state.json。然后运行新版安装助手；旧 App 会另存一份，资料库保持原位。

安装完成后从目标“应用程序”目录启动，检查卡片、草稿与接收设置。不要同时运行两份 App。本版没有自动更新。

## 常用操作

- 普通卡片单击复制；记事卡单击继续编辑。
- 点小红段记事，普通 Return 换行，Command＋Return 挂上，Esc 收起并保留草稿。
- 右键卡片查看来源、详情和副本操作。
- 满绳后用触控板横滑、Shift＋滚轮或底部箭头浏览。
- “设置 → 存储 → 预览清理…”确认后移到废纸篓，不自动清空。

## 回退与卸载

回退先退出新版，再换成安装助手保留的旧 App。恢复资料备份前，先保护当前新增内容；已有同名目录时停止，不能直接覆盖合并。

卸载只需退出后把 App 移到废纸篓，资料库会保留。若还要移除资料库，先完整备份、确认不再需要，再移到废纸篓；不要在应用运行时操作。

## 校验与问题处理

SHA-256 和版本信息均在官网同版下载区。助手会检查随包文件一致性；它不认证开发者身份。若系统检测到恶意软件、校验失败或来源不可信，应停止，而不是关闭全局系统保护。

看不到绳子时先试 Control＋Option＋T；仍是旧界面时确认旧版已退出并从新安装位置启动。拖入目标输入框失败，可用“复制 → 目标应用 Command＋V”。微信／Codex、Intel／旧系统等完整边界见“本版限制.md”。
