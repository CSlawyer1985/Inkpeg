# 0.1.0 内部测试版限制

更新：2026-10-10。安装包用于当前功能试用，不能作为完整 1.0 或正式安全发行。

| 范围 | 当前状态 |
| --- | --- |
| 原生面板、记事粘贴、存储清理 | 已实现；232 项完整自动测试通过，中文记事粘贴与隔离资料清理有实际原生界面证据。 |
| 微信／Codex 输入框拖入 | 直接拖入并变成文字／图片粘贴的兼容仍待完成；先用“复制 → 目标应用 ⌘V”。 |
| 满绳与横向滚动 | 显示容量受当前布局限制；溢出旧未固定卡会取下并保留副本。未实现按宽度挂满及触控板横向滚动。清理可能包含这些取下资料，请核对预览。 |
| 事项／历史、固定操作、双栏对照 | 模型部分字段存在，完整用户流程尚未实现，不宣传已支持。已有 pinned 状态的资料受清理保护。 |
| 一键隐私 | 部分操作保护存在，完整持久开关与全窗口遮盖未接通。 |
| 自定义资料库路径 | 尚未实现；默认 `~/Library/Application Support/Inkpeg/`。 |
| 系统与架构 | 安装包仅 arm64。工程最低 macOS 14，本机 macOS 26.6.2；旧系统、新机、Intel、跨屏和完整中文输入法交互尚未完成验收。 |
| 签名与公证 | 无 Developer ID／Apple 公证。可执行文件的 linker ad hoc 签名不是开发者身份认证。首次下载后的 Gatekeeper 步骤需要用户自行确认，未进行新机测试。 |
| 安装与升级 | DMG 内容、校验、独立资源及隔离启动可本机验证；覆盖安装和下载隔离弹窗尚待测试者在独立环境验证。只更换 app，保留资料库。 |
| 恢复与清理 | 草稿及未知恢复记录保护；回收文件可找回后重新挂入，不自动恢复旧卡片。废纸篓访问失败不宣称已核验，需检查结果。 |
| 网络与隐私验收 | 没有业务联网功能；完整运行时网络观察仍未完成。 |
| 发行资产 | 采用独立名称，未使用上游图标或演示图；本版使用系统通用应用图标，正式独立品牌图标尚待制作。 |

正式发布仍需补齐首版功能、真实交互及平台验收、独立图标、Developer ID 签名、公证／staple 和 Gatekeeper 验证。历史发布计划保留在工程的 docs/inkpeg 目录。
